# 도움말 · S15P31D101-311

`/help`에서 처음이라면·단축키·말로 하는 명령을 제공한다. 공통 헤더와 안내 띠는 기존 AppLayout을 사용한다.

- 처음이라면: 기존 `/tutorial/1`부터 `/tutorial/4`까지 필요한 단계로 이동한다.
- 단축키: 어디서나·재생과 이동·질문과 설정. 어디서나 목록은 현재 등록된 단축키에서 가져온다. 영상 전용 키는 실제 Player·SeekBar·AskPanel의 적용 위치를 함께 표시한다.
- 말로 하는 명령: 재생 조절·장면 찾기·질문과 해설, 분류별 예시 4개. 기존 영상 화면의 음성·글자 입력을 설명하며 도움말에서 마이크를 켜지는 않는다.
- 문제 해결: 음성 입력 실패와 단축키 충돌 안내를 공통 Dialog로 표시한다. 닫기·Esc 후 열었던 버튼으로 초점이 돌아간다.

## 디자인과 실제 동작

수정본의 탭·3단계 카드·명령/설명 표 배치를 사용한다. 색상·글꼴·크기는 앱 토큰과 공통 부품을 따른다. 모바일과 큰 글씨에서는 카드를 세로로 배치하고 표 내용은 줄바꿈한다.

- [단축키 수정본](https://www.figma.com/design/6NaOLfDXCAezgQM0GNacI5/Audisay?node-id=514-1382)
- [말로 하는 명령 수정본](https://www.figma.com/design/6NaOLfDXCAezgQM0GNacI5/Audisay?node-id=514-1729)

현재 구현과 다른 와이어프레임 문구는 그대로 옮기지 않는다. 음성 시작 키는 Alt+Shift+Q이며 ‘말 끝내기’ 후 요청을 처리한다. ‘아니’ 자동 재청취와 Alt+Shift+V는 제공되지 않는다. Alt+Shift+S는 설정 창이 아닌 요약 듣기다. 음성 신고는 현재 서버에서 버튼 사용을 안내하므로 예시는 ‘요약 들려줘’로 대체했다. 기존 플레이어와 음성 입력 동작은 변경하지 않는다.

## 확인

`help.test.tsx`는 실제 라우트에서 진입 초점, 튜토리얼 이동, 두 단계 탭의 키보드 이동, 등록된 단축키 일치, 여섯 분류, 두 모달의 닫기·초점 복귀 및 axe 검사를 확인한다. 네이티브 모달의 배경 차단과 Esc는 브라우저에서도 확인한다.

도움말 자체의 새 API는 없다. 사용법 링크와 안내는 기존 화면을 이용하며, 음성 인식·질문·명령 처리는 기존 영상 화면 API가 담당한다.
