# 도움말 · S15P31D101-311

`/help`는 단축키 탭으로 진입한다. 메뉴는 단축키·말로 하는 명령·튜토리얼 이동 순서다. 공통 헤더와 안내 띠는 기존 AppLayout을 사용한다.

- 튜토리얼 이동: 탭이 아닌 링크로 `/tutorial/1`에 바로 이동한다. 별도의 사용법 카드 화면을 만들지 않는다.
- 단축키: 어디서나·재생과 이동·질문과 설정, 각각 4·4·5행을 수정본 문구 그대로 표시한다.
- 말로 하는 명령: 재생 조절·장면 찾기·질문과 해설, 분류별 예시 4개. 도움말에서 마이크를 켜지는 않는다.

## 디자인과 실제 동작

수정본의 IBM Plex Sans KR 400·700 글꼴을 자체 호스팅한다. 본문 24px·보조 22px·제목 36px·버튼 56px를 rem으로 적용한다. 1440px 디자인의 콘텐츠 폭 1312px, 메뉴 폭 128·224·176px와 간격 16px, 안내 카드 100px, 표 열 1:1·행 56px(5행일 때 52px)를 기준으로 한다. 공통 Tabs·ButtonLink를 재사용하고 고대비 설정을 반영한다. 작은 화면에서는 음성 안내 카드를 세로로 배치하고 표 내용은 줄바꿈한다. 최신 수정본에 없는 문제 해결 보조 버튼과 연결 모달은 제공하지 않는다.

- [단축키 수정본](https://www.figma.com/design/6NaOLfDXCAezgQM0GNacI5/Audisay?node-id=514-1382)
- [말로 하는 명령 수정본](https://www.figma.com/design/6NaOLfDXCAezgQM0GNacI5/Audisay?node-id=514-1729)

사용자가 플레이어 담당자가 나중에 기능을 추가한다고 확인했으므로, 안내 문구는 수정본 그대로 유지한다. Alt+Shift+V, ‘아니’ 재청취, Alt+Shift+S 설정 열기 등은 현재 플레이어와 차이가 있다. 이번 변경은 도움말의 표시만 구현하며 기존 플레이어·음성 입력·공통 단축키 등록 동작을 변경하지 않는다. 담당자의 기능 추가 후 연결 검증이 필요하다.

## 확인

단축키·음성 입력 단계·음성 명령 표는 화면에 수정본 표기를 유지하고 낭독용 한국어 문장을 별도로 제공한다. `HelpReadableText`는 기호가 있는 표시 텍스트만 `aria-hidden`으로 숨기고 `sr-only` 텍스트를 한 번 제공한다. 표·행·열 제목 구조는 유지하며 정적 본문에 `aria-label`이나 추가 Tab 정지를 붙이지 않는다. 슬래시 키 자체와 선택지 구분을 구별하고, 복수 명령과 설명은 각각의 의미를 풀어 읽는다. 공통 헤더·전광판·단축키 안내 창의 표시나 동작은 변경하지 않는다.

`help.test.tsx`는 실제 라우트에서 단축키 기본 진입과 제목 초점, 메뉴 순서·튜토리얼 이동, 두 단계 탭의 키보드 이동, 수정본의 여섯 분류 및 axe 검사를 확인한다. 공통 Tabs의 선택형 메뉴와 이동 링크는 역할을 구분하고 DOM 순서와 화면 순서를 일치시킨다.

도움말 자체의 새 API는 없다. 사용법 링크와 안내는 기존 화면을 이용하며, 음성 인식·질문·명령 처리는 기존 영상 화면 API가 담당한다.
