- [Figma 내 영상](https://www.figma.com/design/6NaOLfDXCAezgQM0GNacI5/Audisay?node-id=514-1103), [즐겨찾기](https://www.figma.com/design/6NaOLfDXCAezgQM0GNacI5/Audisay?node-id=514-1542)

## 연동

| 기능                            | API (기존 `/api/v1` 클라이언트 사용) |
| ------------------------------- | ------------------------------------ |
| 요청·올린 영상, 최근 요청순     | `GET /users/me/videos?page=&size=4`  |
| 즐겨찾기, 최근 추가순           | `GET /favorites?page=&size=4`        |
| 채널명·소유 여부·공개 범위 확인 | `GET /videos/{videoId}`              |
| 즐겨찾기 해제                   | `DELETE /favorites/{videoId}`        |
| 본인 업로드 공개 범위 변경      | `PATCH /videos/{videoId}/visibility` |
| 해설 다시 요청                  | `POST /videos/{videoId}/retry`       |
| 오늘 남은 횟수                  | `GET /users/me/quota`                |

목록 응답에 소유자·공개 범위가 없으므로 상세 응답을 확인한 뒤 공개 변경 버튼을 표시한다. 실패 원인은 목록에 없으므로 임의로 ‘시간 초과’라고 표시하지 않는다. 해설 없는 유튜브 즐겨찾기는 기존 주소 확인 화면을 거쳐 요청한다. 시청·작업 진행 화면은 기존 라우트로 연결한다.

홈과 같이 한 열 목록(ol)으로 10개씩 보여 주고 '더 보기'로 이어 붙인다. 늘 첫 쪽부터 불러온 개수(size=shown, 50개 초과는 나눠 받음)만큼 다시 받고 videoId 로 중복을 거른다. 탭과 불러온 개수는 주소(?tab=&shown=)에 남긴다. 즐겨찾기 변경은 목록 수·다른 영상 목록의 상태를 갱신한다.

## 접근성·확인

- 기존 페이지 진입·안내 훅과 공통 UI를 사용한다. 탭은 화살표로 이동한다. 더 보기 뒤에는 새로 붙은 첫 영상 제목으로, 카드 해제 시 목록 제목으로 초점을 옮긴다.
- 썸네일은 장식 이미지, 반복 버튼 이름에는 영상 제목을 제공한다. 제작 중 목록은 5초마다 갱신하되 완료·실패 전환 때만 알린다.
- 빈 목록·로딩·실패·재생 불가 상태를 제공한다. 720px 이하에서는 카드를 한 열로 표시하며 큰 글씨·고대비 토큰을 따른다.
- `my-videos.test.tsx`: 목록·탭·더 보기·권한별 버튼·변경 성공/실패·재요청·빈 목록·오류 복구·axe 검사.
- `npm run lint`, 전체 테스트 125개(`npm test -- --maxWorkers=1`), `npm run build`를 통과했다.
- 2026-11-02 테스트 계정으로 목록·상세·이용 횟수 조회, 즐겨찾기 추가·화면에서 해제, 공개·비공개 변경 및 새로고침 후 저장 상태를 확인했다. 테스트 변경은 원래 상태로 복구했다.
- 실패·제작 중 영상과 다중 페이지 실데이터가 없어 이 경우의 실제 서버 흐름은 아직 확인하지 못했다. NVDA/센스리더 실제 낭독 검사도 남아 있다. 개발용 예시 화면은 제거했다.
- 기존 공통 헤더는 360px에서 가로 넘침이 관찰됐다. 이 작업에서는 공통 헤더를 변경하지 않았다.
